# Этап 7 — История метрик + Settings

## Backend

1. Агрегатор: раз в минуту сворачивает кольцевой буфер в metrics_1m
   (cpu_pct avg, mem, disk/net JSON)
2. Ретенция: фоновая очистка > 7 дней + периодический VACUUM (разд. 10 ТЗ)
3. `GET /metrics/nodes/{id}?window=1h|6h|24h|7d&step=60s` — из SQLite;
   window=15m — из буфера (уже есть с этапа 2)
4. Settings API: смена пароля, ротация agent-token (+ уведомление о
   необходимости redeploy агентов), пороги алертов, ретенция

## Frontend

1. Node detail: селектор окна 15м/1ч/6ч/24ч/7д (график переключается
   live-буфер ↔ история)
2. Экран Settings: смена пароля, ротация join/agent-token, пороги,
   ретенция, переключатель языка EN/RU

## Критерии проверки

- [ ] go test: агрегация 1м из буфера, очистка ретенции
- [ ] График 24ч строится из SQLite после накопления данных
- [ ] Смена пароля инвалидирует старый
