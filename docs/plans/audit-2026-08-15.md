# Аудит проекта — 15.08.2026

Сверка кода с ТЗ v1.2 и планами этапов 1–9. Ниже — **полный реестр** найденного:
дыры, ошибки, долги и предложенные улучшения. Каждый пункт имеет ID (`A-xx`),
на который ссылаются планы этапов 10–13.

**Что на момент аудита зелёное:** `go build` / `go vet` / `go test ./...` в
`panel`, `npm run build` (vue-tsc + vite) во `frontend`, все 8 этапов v1
реализованы, FR-14 работает в базовом объёме, ТЗ и планы синхронны по составу.

## Категория 1. Дыры FR-14 (высокий риск — тихая потеря конфигурации)

| ID | Находка | Где | Риск |
|---|---|---|---|
| A-01 | `volumes:` сервиса не конвертируются вообще — `Mounts` в спеке не заполняется | `internal/stackspec/convert.go:85-133` | **Критический.** Стек с БД поднимется без тома → потеря данных при рестарте задачи |
| A-02 | `secrets:` / `configs:` сервиса не конвертируются и не создаются, хотя ТЗ 3.14.5/3.14.8 их требует | `convert.go`, `handlers_stackdeploy.go:114-178` | **Высокий.** Сервис стартует без секретов и падает в рантайме |
| A-03 | Неподдерживаемые поля compose игнорируются молча; `validate` не отдаёт предупреждений | `handlers_stackdeploy.go:78-97` | **Высокий.** Пользователь видит «всё ок» и получает неполный стек |
| A-04 | Создаваемые сети не получают label `com.docker.stack.namespace` | `handlers_stackdeploy.go:130`, `dockerapi/resources.go:68` | Средний. Сети не опознаются как часть стека при удалении |
| A-05 | `external`-ресурсы не проверяются на существование при валидации | `stackspec/load.go` (`SkipConsistencyCheck`) | Средний. Ошибка всплывает только в момент деплоя, невнятным текстом |
| A-06 | Нет лимита размера тела на `/stacks*` (`MaxBytesReader` стоит только на `/ingest`) | `handlers.go:148` vs `handlers_stackdeploy.go` | Средний. Большой YAML → рост памяти панели |
| A-07 | Не покрыты поля: `user`, `working_dir`, `hostname`, `stop_grace_period`, `sysctls`, `cap_add/drop`, `logging`, `dns`, `init`, `read_only`, `privileged`, `deploy.endpoint_mode`, `placement.preferences`, `placement.max_replicas_per_node`, driver-opts сетей | `convert.go` | Средний.
